# Установка через Honor9-HarmonyOS2-Downloader.exe

[English version](EXE-GUIDE-EN.md)

Это рекомендуемый способ установки. Одна программа скачивает файлы с GitHub,
проверяет их, проверяет телефон и выполняет прошивку. Отдельно запускать CMD или
PowerShell не требуется.

## 1. До запуска

Подготовьте:

- Honor 9 `STF-AL00/AL10/TL10/L09/L19` на EMUI 9.x;
- `USER LockState: UNLOCKED` и `FB LockState: UNLOCKED`;
- Windows 10/11 x64 и не менее 10 ГиБ свободного места;
- заряд телефона не менее 50%;
- резервную копию всех личных данных.

Если FBLOCK ещё включён, сначала выполните
[`FBLOCK-GUIDE-RU.md`](FBLOCK-GUIDE-RU.md).

Внутренняя память будет полностью удалена. microSD не форматируется.

## 2. Скачивание EXE

1. Откройте актуальный раздел [Releases](../../releases/latest).
2. Скачайте `Honor9-HarmonyOS2-Downloader.exe`.
3. Проверьте SHA-256 по `SHA256SUMS.txt` Release.
4. Запустите EXE. Если Windows SmartScreen показывает предупреждение, проверьте
   имя файла и SHA-256, затем выберите **Подробнее → Выполнить в любом случае**.

Программа не требует установки. Она использует .NET Framework из Windows.

## 3. Подготовка файлов

1. В поле **Папка установщика** выберите короткий путь на внутреннем диске,
   например `C:\Honor9Harmony`.
2. Дождитесь автоматической проверки GitHub Release или нажмите
   **Проверить GitHub**.
3. Выберите PREAS:
   - **неподписанный** — изменённый минимальный `/china`, проверен на STF-AL10;
   - **подписанный Huawei** — официальный китайский PREAS из HarmonyOS
     2.0.0.140, экспериментальный с системой 2.0.0.150.
4. Нажмите **1. Скачать и подготовить**.
5. Дождитесь сообщения **КОМПЛЕКТ ГОТОВ**.

Программа поддерживает продолжение загрузки после обрыва. Она проверяет
SHA-256 каждого Release asset, безопасно распаковывает base ZIP и проверяет
собранный `payload.7z`. Для подписанного варианта отдельно скачивается только
выбранный PREAS.

## 4. Подключение телефона

1. Полностью выключите телефон.
2. Закройте HiSuite и другие программы ADB/Fastboot.
3. Зажмите уменьшение громкости.
4. Подключите телефон к ПК по USB, не отпуская кнопку.
5. Дождитесь Fastboot/Rescue Mode.
6. Убедитесь, что экран показывает оба состояния `UNLOCKED`.

## 5. Проверка телефона

1. Нажмите **2. Проверить телефон**.
2. Программа проверит:
   - наличие ровно одного устройства;
   - модель семейства STF;
   - разблокированный USERLOCK;
   - отключённый FBLOCK;
   - установленную EMUI 9.x или подходящую HarmonyOS.
3. Продолжайте только после сообщения **CHECK PASSED**.

Проверка ничего не прошивает и не удаляет.

## 6. Прошивка

1. Нажмите **3. Прошить телефон**.
2. Проверьте выбранный вариант PREAS в окне подтверждения.
3. Введите точно `STF-HARMONY-ERASE`.
4. Нажмите **Начать прошивку**.
5. Не отключайте USB, не закрывайте EXE и не нажимайте пункты TWRP.
6. Следите за журналом в окне и дождитесь сообщения **DONE**.

Обычно процесс занимает 30–60 минут. Большие разделы могут несколько минут
оставаться на `Sending` или `Writing`.

## 7. После установки

- первая загрузка может занять 10–15 минут;
- никогда не блокируйте bootloader, независимо от выбранного PREAS;
- не устанавливайте OTA поверх этой смешанной установки;
- сохраните папки `backups` и `logs`;
- никому не передавайте `backups`: там находятся уникальные данные телефона.

Подписанный PREAS подтверждает только его AVB-подпись Huawei. Он не доказывает
безопасность relock и пока считается экспериментальным с системой 2.0.0.150.

## 8. Ошибки

- **Подписанный PREAS недоступен** — он отсутствует в выбранном Release;
  используйте неподписанный вариант или обновите список Release.
- **SHA-256 не совпадает** — файл повреждён; не прошивайте, повторите загрузку.
- **FBLOCK is locked** — отключите FBLOCK по отдельной инструкции.
- **Fastboot device did not appear** — проверьте драйвер, кабель и USB-порт.
- **ERROR/FAILED во время прошивки** — не выполняйте relock, сохраните журнал и
  резервные копии.

Используйте пакет на свой страх и риск.
