# Changelog

## v1.1.0

- добавлен единый GUI `Honor9-HarmonyOS2-Downloader.exe`;
- добавлены докачка, проверка GitHub digest/SHA-256 и автоматическая распаковка;
- проверка телефона и прошивка перенесены в единое окно с журналом;
- добавлены собственная иконка и пошаговые русская/английская инструкции;
- кнопка прошивки активируется только после успешного `CHECK PASSED`;
- добавлены звуковые подсказки ручного входа в Fastboot/TWRP;
- ожидание переходов увеличено до пяти минут;
- signed PREAS отключён до появления проверенного китайского `/china`-дампа;
- добавлены шаблон bug report и правила безопасной публикации логов.

## v1.0.0

- первая публичная версия офлайн-установщика HarmonyOS 2.0.0.150;
- автоматическая проверка STF-модели, USERLOCK и FBLOCK;
- персональный патч собственного OEMINFO без подмены идентификаторов;
- резервное копирование уникальных разделов;
- payload разделён на Release assets из-за лимита GitHub;
- русская и английская документация.
